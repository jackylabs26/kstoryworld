## 후보별 가필 계획

### 1. 도깨비 (Goblin) — `goblin-en.html` / `goblin-ko.html`

현재 상태: TMDB 단일 소스 기반 종합 리뷰. 플롯·캐스트·추천 이유·최종 감상 구성. 톤은 일반 리뷰 블로그 스타일로, KStoryWorld 에디토리얼 보이스(큐레이션·관찰형)와 괴리가 있음.

<strong>1차 출처 보강</strong>
- tvN 공식 프로그램 페이지 / tvN 방영 데이터 인용
- 공유(Gong Yoo) 인터뷰: 도깨비 캐스팅 비화, 캐릭터 해석 (예: 유퀴즈·나혼산 출연분 등)
- 김은숙 작가 인터뷰: 집필 동기, 판타지 로맨스 장르 선택 이유
- OST 정보: 찬열·펀치 "Stay With Me", 에일리 "첫눈처럼 너에게 가겠다" — 작곡가·차트 성적·스트리밍 수치

<strong>본문 부족 부분</strong>
- 제작 배경: 김은숙 작가 × 이응복 PD 콤비의 tvN 역사적 의미, 촬영지(캐나다 퀘벡 등)
- 한류 임팩트: 퀘벡 관광 붐, 동남아·중동 팬덤 확산, 후속 판타지 드라마에 미친 영향
- 에피소드별 변화: 전반부 코믹 로맨스 → 후반부 비극적 판타지로의 톤 전환 분석

<strong>이미지 보강 (F4 통합)</strong>
- 메인 포스터 고해상도 교체 (현재 TMDB w500 → 공식 포스터 또는 Pexels 분위기컷)
- 촬영지 사진 (퀘벡 메이플 거리, 인천 송도 등)
- 캐스트 프로필 이미지 최소 2장 추가

<strong>자체 분석 섹션 (목표 600+ 단어)</strong>
- "왜 도깨비는 2016년 이후에도 계속 회자되는가" — 판타지 로맨스의 한국적 변용, 죽음과 기억의 모티프가 한국 정서(한·情)와 맞닿는 지점, 시청자가 일상에서 발견하는 '도깨비 순간'의 문화적 의미

### 2. 사랑의 불시착 (Crash Landing on You) — `crash-landing-on-you-en.html` / `crash-landing-on-you-ko.html`

현재 상태: TMDB 단일 소스 기반. 남북 로맨스 구조 설명에 치중, 사회적 맥락·제작 비하인드 부재.

<strong>1차 출처 보강</strong>
- tvN / Studio Dragon 공식 제작 정보
- 현빈·손예진 공동 인터뷰 (백상예술대상 수상 소감, 해외 팬미팅 발언 등)
- 박지은 작가 인터뷰: 탈북자 취재 기반 각본 작업 과정
- OST 정보: 윤미래 "Flower", 10cm "나의 어깨 위로" — 작곡 배경·차트 기록

<strong>본문 부족 부분</strong>
- 제작 배경: 스위스 로케이션 촬영 비하인드, 북한 마을 세트 고증 과정
- 한류 임팩트: COVID-19 시기 Netflix 글로벌 흥행과 한국 드라마 붐의 기폭제 역할, 일본·동남아 팬덤 폭증, 현빈-손예진 실제 결혼으로 이어진 리얼 로맨스 화제성
- 남북 소재의 문화적 맥락: 분단 서사의 한국 드라마 계보 (JSA → 이산가족 찾기 → CLOY)

<strong>이미지 보강 (F4 통합)</strong>
- 공식 포스터 고해상도 교체
- 스위스 촬영지(이젤발트 호수 등) 풍경 사진
- 북한 마을 세트 장면 또는 분위기 연출컷

<strong>자체 분석 섹션 (목표 600+ 단어)</strong>
- "금지된 경계를 넘는 사랑 — 분단 서사가 로맨스 장르를 만났을 때" — 한국 사회에서 '북한'이라는 소재가 엔터테인먼트로 소비되는 방식의 변화, CLOY가 해외 시청자에게 한반도 분단을 '처음으로 감정적으로 이해'시킨 순간, 로맨스 판타지와 정치 현실의 긴장

### 3. 별에서 온 그대 (My Love from the Star) — `my-love-from-the-star-en.html` / `my-love-from-the-star-ko.html`

현재 상태: TMDB 기반 종합 리뷰. 에일리언 로맨스 구조 설명 충실하나 문화적 파급력 분석 전무.

<strong>1차 출처 보강</strong>
- SBS 공식 프로그램 페이지 / 시청률 데이터 (닐슨코리아)
- 김수현 인터뷰: 도민준 캐릭터 준비 과정 (400년 외계인 연기 접근법)
- 전지현 인터뷰: 천송이 캐릭터의 코미디 연기 전환
- 박지은 작가 인터뷰: '별그대' 기획 의도 (CLOY와 동일 작가 — 작가론 연결)
- OST 정보: 효린 "Hello, Goodbye", 김수현 "Promise" — 차트 성적·문화적 임팩트

<strong>본문 부족 부분</strong>
- 제작 배경: 2013년 SBS 수목드라마 경쟁 구도, 조선시대 신윤복 회화와의 시각적 연결
- 한류 임팩트: 중국 시장 폭발 (시진핑 부인 팽리위안 언급설, 중국 치맥 유행의 기원), 한류 2.0→3.0 전환의 분수령
- 시즌/에피소드별 변화: 21화 구성의 서사 아크 — 코미디 전반부 vs 비극적 후반부 전환

<strong>이미지 보강 (F4 통합)</strong>
- 공식 포스터 고해상도 교체
- 조선시대 회상 장면 분위기컷
- 천송이 패션 아이코닉 장면 (치맥 장면 등)

<strong>자체 분석 섹션 (목표 600+ 단어)</strong>
- "별그대가 바꾼 한류의 지도 — K-드라마가 중국 대중문화를 뒤흔든 순간" — 2014년 중국 한류 붐의 실체, '치맥' 문화 수출 현상, 외계인 설정이 '이방인으로서의 한국'이라는 메타포로 작동하는 방식, 박지은 작가의 경계 넘기 서사 계보

### 4. 오징어 게임 (Squid Game) — `squid-game-en.html` / `squid-game-ko.html`

현재 상태: TMDB 기반 종합 리뷰. 사회 비평·캐릭터 분석은 있으나, 시즌별 구분 없이 뭉뚱그려져 있고 1차 출처 전무.

<strong>1차 출처 보강</strong>
- Netflix 공식 시청 데이터 (역대 1위 기록 수치)
- 황동혁 감독 인터뷰: 10년간의 기획 과정, 투자 거절 이력, Netflix 계약 경위
- 이정재 인터뷰: 성기훈 캐릭터 해석, 에미상 수상 소감
- OST 정보: 정재일 스코어, "Way Back Then" (무궁화 테마) — 문화적 밈화

<strong>본문 부족 부분</strong>
- 제작 배경: 2008년 최초 기획 → 2021년 Netflix 글로벌 공개까지의 13년 여정
- 한류 임팩트: 비영어권 콘텐츠 최초 Netflix 글로벌 1위, 에미상 6관왕, 한국어 학습 붐 촉발, 달고나·무궁화 꽃이 피었습니다의 글로벌 밈화
- 시즌별 변화: 시즌1(사회 비평) → 시즌2(확장된 세계관) → 시즌3(결말) 아크 분석

<strong>이미지 보강 (F4 통합)</strong>
- 공식 포스터 고해상도 교체 (현재 TMDB w500)
- 아이코닉 비주얼 (핑크 가드, 영희 인형, 계단 장면) 분위기컷
- 시즌별 키비주얼 추가

<strong>자체 분석 섹션 (목표 600+ 단어)</strong>
- "놀이의 잔혹한 거울 — 오징어 게임이 포착한 글로벌 불평등의 정서" — 한국의 IMF 세대 트라우마가 글로벌 MZ세대 경제 불안과 공명한 이유, 어린이 놀이를 생존 게임으로 전유한 서사 장치의 문화 비평적 의미, Netflix 플랫폼이 비영어 콘텐츠 글로벌화에 미친 구조적 변화

### 5. 더 글로리 (The Glory) — `the-glory-en.html` / `the-glory-ko.html`

현재 상태: TMDB 기반 종합 리뷰. 복수극 구조 분석은 충실하나 학폭 사회 이슈 맥락·제작 배경 부재.

<strong>1차 출처 보강</strong>
- Netflix Korea 공식 홍보 자료
- 김은숙 작가 인터뷰: 학교 폭력 실제 사건 취재 기반, '복수' 서사의 윤리적 고민
- 송혜교 인터뷰: 문동은 캐릭터를 위한 외모·연기 변신 과정
- 임지연 인터뷰: 박연진 악역 연기 접근법
- OST 정보: 테마 음악·삽입곡 정보 (작곡가, 분위기 기여도)

<strong>본문 부족 부분</strong>
- 제작 배경: 파트1(2022.12) → 파트2(2023.03) 분할 공개 전략, 김은숙 작가의 장르 전환(로맨스→복수극)
- 한류 임팩트: Netflix 글로벌 비영어 TV 1위 기록, 한국 학교폭력 이슈의 국제적 조명, 일본·동남아에서의 '학폭 공론화' 촉발
- 파트별 변화: 파트1(복수 설계) → 파트2(복수 실행·결말) 톤 전환, 바둑 모티프의 서사적 기능

<strong>이미지 보강 (F4 통합)</strong>
- 공식 포스터 고해상도 교체
- 문동은 캐릭터 키비주얼 (바둑 장면, 학교 장면)
- 파트1·파트2 대비 분위기컷

<strong>자체 분석 섹션 (목표 600+ 단어)</strong>
- "복수는 치유가 될 수 있는가 — 더 글로리가 던진 한국 사회의 질문" — 한국 학교폭력 실태와 드라마 속 재현의 간극, 복수극이 '사적 정의'를 정당화하는 방식에 대한 사회적 논쟁, 김은숙 작가가 로맨스에서 복수극으로 전환하며 발견한 '관계의 어두운 면', 파트2 결말의 카타르시스와 그 한계
