# KStoryWorld · Marketing UI Kit

Public website. Light canvas, pastel-bloom hero, seasonal collection rows, dark research footer. Mirrors the homepage of the brand.

## Components
- `Header.jsx` — sticky glass-blur nav with logo, links, CTA
- `Hero.jsx` — pastel-bloom hero with display headline + dual CTA
- `Stats.jsx` — three big numbers, mono captions
- `SeasonRow.jsx` — story collection grid keyed to a season (봄/여름/가을/겨울)
- `StoryCard.jsx` — editorial card with seasonal thumb
- `ResearchSection.jsx` — dark midnight zone with paper cards
- `Footer.jsx` — full-bleed dark with giant `kstoryworld` wordmark

## Run
Open `index.html` directly.
