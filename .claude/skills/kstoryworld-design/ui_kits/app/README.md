# KStoryWorld · Reader App UI Kit

The product app — Discover, Story Reader (light + dark), Library. Click between screens via the bottom-right segment.

## Components
- `AppShell.jsx` — sidebar nav + main column
- `Discover.jsx` — discover feed by season
- `StoryReader.jsx` — long-form reader with audio bar, glossary
- `Library.jsx` — saved stories grid

## Run
Open `index.html` directly.
