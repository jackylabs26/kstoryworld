Brand snapshot

KStoryWorld is a storytelling-led brand: Korean folk tales, K-drama narratives, K-pop documentaries, and modern Korean voices, all under one roof. The platform sits between enterprise-clean infrastructure (catalog, partner network, dashboards) and emotional, human storytelling (literary, cinematic, atmospheric).

The three pillars

  • Geometry & type discipline — sharp 4 px corners, "The Future" display, PP Neue Montreal Mono labels, midnight-blue dark mode (#010120).
  • Korean four-seasons palette — pastels named for 봄·여름·가을·겨울 (spring, summer, autumn, winter) layered over white canvas.
  • Editorial restraint — generous whitespace, mono labels as signposts, oversized stats and oversized hangul wordmarks as closing brand moments.

Type stack per locale

Every text style in colors_and_type.css falls back through a CJK-aware stack. The --font-display variable already chains Latin → Hangul → CJK fallbacks. Recommended additions per locale:

  • ko — Pretendard → Apple SD Gothic Neo → Noto Sans KR → system Hangul
  • ja — Inter → Noto Sans JP → Hiragino Sans → system JP
  • zh-Hans — Inter → Noto Sans SC → PingFang SC → system SC
  • zh-Hant — Inter → Noto Sans TC → PingFang TC → system TC
  • es · fr · vi — Space Grotesk → Inter → system sans

Set <html lang="…"> and add :lang(ko), :lang(ja) font-family overrides in colors_and_type.css so each locale picks the correct stack automatically.

Layout rules for i18n

  • String budget — design layouts assuming text can grow up to +30% (German / French) or shrink −20% (CJK). Never hard-cap a headline to its English length.
  • Line-height — bump to 1.6 for vi (diacritics), 1.30 for CJK display, 1.40 for Latin body.
  • Letter-spacing — negative tracking on "The Future" applies to Latin only. CJK display uses letter-spacing: 0; never apply negative tracking to hangul, kana, or hanzi.
  • Mono labels — ALL CAPS only applies to Latin. For CJK, render mono labels in their natural case at the same size and color.
  • Bilingual pairings like 봄 · spring become trilingual or single depending on locale. The · separator stays.
  • RTL — not currently in scope, but layouts use padding-inline, margin-inline, and other logical properties so adding Arabic / Hebrew later requires no rework.

Translation workflow

  • Source strings are Korean (ko); English is the working pivot.
  • Each story carries a translator credit ("Translated by …"). The same convention applies to UI strings — translators are credited in the colophon page.
  • Keys live in i18n/<locale>.json (suggested layout, not yet built).

Content fundamentals

Voice

  • Multilingual-first, with hangul as the source language and visual anchor (section labels, big display moments, proper nouns). On any locale, pair the local language with hangul where it adds meaning: 봄 — Spring · 봄 — 春 · 봄 — Primavera. Never replace hangul entirely on cultural concepts (정 (jeong), 한 (han), p'ansori).
  • Warm, literary, slightly cinematic. Not corporate. Not playful in a startup-mascot way.
  • First person plural ("we") for the platform, second person ("you") for the reader. Never "I."
  • Sentences are short, declarative, image-rich. Verbs do the heavy lifting.

Casing

  • Display headlines — sentence case. Never ALL CAPS in display.
  • Mono labels — ALL CAPS with positive letter-spacing. The only uppercase moments.
  • Buttons — sentence case ("Read the story", "Listen now"). Never Title Case.
  • Korean text — rendered as-is; never forced uppercase (hangul has no case).

Tone examples

  • Hero headline — "Every Korean story, told with care."
  • Section opener — "From p'ansori to K-drama, the thread of 정 (jeong) runs through everything."
  • CTA — "Start with a tale →"  /  "이야기 시작하기 →"
  • Stat caption — "Stories told this season" · 3,200+
  • Section label — 봄  /  SPRING COLLECTION

Vibe

Editorial, atmospheric, quietly proud. Closer to The Paris Review × Apple Newsroom than Duolingo × Memrise.

Visual foundations

Color system — four layers

  • Canvas — Pure White (#ffffff) and Midnight Blue (#010120). White for business / discovery, Midnight for stories / research / footer. The light-dark duality is core.
  • Seasonal accents — four pastel-led palettes (see swatches above), used as decorative gradients, mood backgrounds, and tag colors. Never UI chrome.
  • Brand accents — Magenta (#ef2cc1) and hanji-orange (#fc4c02) appear in illustrations and gradient endpoints only. Never as button fill or text color.
  • Neutrals — pure black, pure white, rgba(0,0,0,0.08) borders on light, rgba(255,255,255,0.12) borders on dark.

Typography

  • Display & body — "The Future" (TTF). Substitute: Inter / system sans. Hangul fallback: Pretendard.
  • Mono labels — "PP Neue Montreal Mono". Substitute: JetBrains Mono. Hangul mono fallback: D2 Coding.
  • Negative tracking on The Future (−1.92px → −0.16px, scaled by size).
  • Mono is always uppercase with positive tracking (+0.05–0.08em).
  • Weights — 400 and 500 only. Never 600+.
  • Line-height tight — 1.00 (display) → 1.30 (body).

Font substitution. We don't have license files for "The Future" or "PP Neue Montreal Mono". The system falls back to Space Grotesk (display) and JetBrains Mono (labels). Drop the real TTFs into fonts/ and uncomment the @font-face block in colors_and_type.css to switch back.

Spacing

  • 8 px base unit. Scale: 1, 2, 4, 8, 12, 16, 20, 24, 32, 44, 48, 80, 100, 120.
  • Section vertical rhythm: 80–120 px (non-negotiable; the open feeling is the brand).
  • Card internal padding: 24–32 px.
  • Button / badge padding: 2 px × 8 px (compact).

Backgrounds

  • Light canvas + soft seasonal gradient blooms — abstract painterly forms (cloud, feather, brush stroke), never literal flowers or mountains.
  • Dark canvas (#010120) is flat — no gradients on dark, ever. Density comes from content.
  • No repeating patterns in production UI. Hangul wordmarks at giant scale are the only "texture."

Animation

  • Easing — cubic-bezier(0.2, 0.8, 0.2, 1) (gentle ease-out). Default duration 240 ms.
  • Hover / focus is opacity + a subtle 2 px Y translate, never a hard color flip.
  • No bounces, no springs — the brand feels composed, not cute.
  • Page transitions: 320 ms cross-fade. Image lazy-loads use 400 ms blur-up.

Borders, radii, shadow

  • Light surfaces: 1px solid rgba(0,0,0,0.08). Dark surfaces: 1px solid rgba(255,255,255,0.12).
  • Radii — 4 px (buttons, badges, tags, inputs), 8 px (cards, modals), 0 px (full-bleed sections, dividers). No pills, no 16 px, no 24 px.
  • One shadow only — rgba(1,1,32,0.10) 0px 4px 10px, tinted midnight blue, never gray. Hover deepens to 0.16.

Layout rules

  • Max content width: 1240 px, centered, 32 px gutters.
  • Sticky header: 64 px tall, becomes glass-blurred on scroll (backdrop-filter: blur(12px), background: rgba(255,255,255,0.72)).
  • Footer — full-bleed midnight blue, with the giant kstoryworld wordmark at scale.

Iconography

KStoryWorld's iconography is lean and editorial. We don't use illustrative or filled-color icon sets.

  • Primary set — Lucide via CDN. Stroke 1.5 px, 24 px box. Their humanist, slightly literary stroke matches "The Future."
  • Mono symbol labels — we often substitute icons entirely with PP Neue Montreal Mono characters (★ → ↗ ·). They read as typography, not chrome.
  • Hangul as glyph — section markers like 봄 여름 가을 겨울 ARE the icons for season-themed surfaces. Rendered in The Future at the size of an icon.
  • No emoji in product UI.
  • Brand marks — a custom KStoryWorld wordmark (assets/logo-kstoryworld.svg) and a square K· lockup for favicon / app icon.
