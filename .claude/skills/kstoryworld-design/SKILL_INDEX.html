How an agent uses this skill

  1. Orient. Read README.html (or README.md) — voice, color, type, multilingual rules.
  2. Pick a season. Ask the user or infer from content: 봄 · 여름 · 가을 · 겨울. Use the matching --*-grad CSS variable.
  3. Pick output mode. For prototypes/mocks, link colors_and_type.css + reuse components in ui_kits/. For production code, lift the tokens.
  4. Set the locale. Wire <html lang=…>. Never strip hangul on cultural concepts (정, 한, p'ansori).
  5. Voice check. Editorial, atmospheric, sentence-case headlines, mono ALL-CAPS labels (Latin only), no emoji in product UI.
  6. Verify. Radii are 4 / 8 / 0. One shadow only. Mobile breakpoint at 768px. No tofu boxes for any locale.
